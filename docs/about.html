System Architecture & Prediction Algorithm

A technical breakdown of the multi-factor mathematical model and personalized recommendation pipeline.

Weak-Topic Detection Logic

Instead of hardcoded arbitrary flags, performance is dynamically evaluated per topic across every quiz attempt:

Percentage = (Correct Answers / Total Questions Attempted) × 100
  • Weak Topic Threshold: < 60%
  • Average Topic Threshold: 60% - 75%
  • Strong Topic Threshold: > 75%

Thresholds are externally configurable via application.properties for runtime adaptability.

Multi-Factor Risk Model

The prediction risk score (0 - 100) incorporates 5 weighted metrics:

Prediction Risk =
  40% Historical Performance Risk +
  25% Recent Performance Risk +
  15% Wrong Answer Rate +
  10% Performance Trend Risk +
  10% Learning Activity / Inactivity Risk
  • HIGH RISK: Risk Score ≥ 70.0%
  • MEDIUM RISK: Risk Score 50.0% - 69.9%
  • LOW RISK: Risk Score < 50.0%

Architectural Design

Presentation Layer

HTML5, CSS3, Bootstrap 5, Chart.js, Vanilla ES6 JavaScript modules with Fetch REST client.

Service & Logic Layer

Java 17, Spring Boot 3 REST Controllers, Spring Security with BCrypt, Strategy Pattern (PredictionStrategy).

Persistence Layer

MySQL 8.0, Spring Data JPA, Hibernate ORM with indexed foreign keys and cascade rules.
